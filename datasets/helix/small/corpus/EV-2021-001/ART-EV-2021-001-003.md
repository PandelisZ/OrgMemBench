# API Pivot Discussion — 2021-04-15

**Attendees:** Maya Patel, Luis Hernandez, Arjun Mehta  
**Note-taker:** Arjun Mehta

## Agenda

- Review customer pain points with spreadsheet integration
- Evaluate feasibility of API-first architecture
- Discuss resource reallocation and funding needs

## Discussion

- **Maya:** “Spreadsheets are a bottleneck for scaling. Clients are asking for real‑time data feeds.”  
- **Luis:** “Investors are pushing us toward an API-first model to stay competitive.”  
- **Arjun:** “We have the engineering capacity to build a robust API layer if we shift focus.”  
- **Maya:** “Let’s target a Q3 launch and secure a seed round to fund the transition.”  
- **Luis:** “Agree. We’ll need to update the roadmap and reallocate resources accordingly.”  
- **Arjun:** “I’ll draft the API specs and coordinate with the product team.”

## Decisions

- Pivot from spreadsheet-centric integration to an API-first architecture.  
- Reallocate engineering resources to build the API layer.  
- Update product roadmap and pursue a new funding round.  
- Set target launch for the API platform in Q3 2021.

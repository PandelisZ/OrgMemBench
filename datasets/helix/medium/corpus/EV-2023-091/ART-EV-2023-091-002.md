# Load Balancer Health Check Review — 2023-07-10

**Attendees:** Ethan Brooks, Emily Zhao, Maya Patel, Rajesh Kumar  
**Note-taker:** Emily Zhao

## Agenda

- Review recent order drop incidents  
- Discuss load balancer health check configuration  
- Plan rollback and hotfix strategy  

## Discussion

- **Ethan:** “We’ve seen 150 orders drop since the last deployment. I think the LB health checks are the culprit.”  
- **Emily:** “Agreed. The current health check endpoint is `/healthz` but it only returns 200 when the DB is up. If the DB hiccups, the LB still routes traffic.”  
- **Maya:** “Could we add a readiness probe that checks the DB health separately?”  
- **Rajesh:** “That would add latency. Maybe we can tweak the LB’s health check interval and threshold instead.”  
- **Emily:** “Let’s roll back to the previous stable config and apply a quick patch to the LB health check settings. We’ll monitor the traffic post‑rollback.”  
- **Ethan:** “Once we confirm stability, we’ll update the Confluence quick‑start guide and add a new monitoring rule for misconfigurations.”  

## Decisions

- Rollback to the last stable load balancer configuration.  
- Apply a hotfix to the LB health check settings (interval + threshold).  
- Update Confluence quick‑start guide.  
- Add a new monitoring rule to alert on similar misconfigurations.

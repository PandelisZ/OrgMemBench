Hi Nia,

Checked the metrics – the new `/v2/shipments/status` endpoint is hitting 10k RPS, saturating the `shipments` table. I added a temporary throttling rule (max 2k RPS) and pushed a Redis cache layer for the status payload. Latency is now below SLA.

We should add a monitoring alert for this endpoint. Let me know if you need more help.

Issue resolved.

Best,
Emily

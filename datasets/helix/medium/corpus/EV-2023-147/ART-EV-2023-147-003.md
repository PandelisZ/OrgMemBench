# Postmortem: API Outage due to Misconfigured Load Balancer — 2023-11-01

**Incident date:** 2023-10-20  
**Severity:** SEV-2  
**Authors:** Emily Zhao, Ethan Brooks

## Summary

On 2023-10-20, the Helix API experienced a 2‑hour outage caused by a misconfigured load balancer that stopped routing traffic after a recent deployment. The outage affected all mid‑market freight‑forwarding customers using the API, leading to delayed shipment tracking and order processing. The incident was resolved by rolling back the deployment, patching the load balancer settings, and deploying a circuit breaker to isolate the failing service.

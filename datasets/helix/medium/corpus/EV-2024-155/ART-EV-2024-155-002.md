# Incident: 3‑hour API outage — INC-2023-10-12-01

**Status:** Investigating  
**Severity:** SEV-2  
**Started:** 2023-10-12 09:15  
**Resolved:** TBD  
**Customer impact:** All API consumers experienced 3‑hour downtime; order placement and tracking services were unavailable.  
**Incident commander:** Maya Patel  

## Current understanding

The outage began at 09:15 UTC when the API gateway reported a 502 error for all incoming requests. Initial diagnostics point to a mis‑configured load balancer that failed to route traffic to healthy instances. We are currently verifying the load balancer configuration and health‑check settings.

## Timeline (live‑updated)

- 09:15 — API gateway reports 502 errors; traffic drops to 0.  
- 09:18 — Incident commander notified; SRE team on call.  
- 09:20 — Load balancer health‑check status shows all instances unhealthy.  
- 09:22 — Re‑checked load balancer config; found missing health‑check path.  
- 09:25 — Updated health‑check path; instances begin to report healthy.  
- 09:30 — API traffic resumes; latency within normal range.  

## Mitigation

- Updated load balancer health‑check path to `/health`.  
- Restarted load balancer service to apply new config.  
- Monitored traffic and latency; all metrics back to baseline.  

## Customer comms

- 09:18 — Sent Slack alert to Ops and Customer Success.  
- 09:25 — Customer Success sent email to affected clients: “We are investigating a 502 error on the API gateway. Work is underway.”  

## Next update

- 09:45 — Final verification of traffic stability.  
- 10:00 — Incident resolved; will post a full post‑mortem.

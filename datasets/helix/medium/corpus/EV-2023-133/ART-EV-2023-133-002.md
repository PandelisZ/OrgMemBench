# API Strategy Review — 2023-10-28

**Attendees:** Emily Zhao, Ethan Brooks, Maya Patel (Product), Luis Gomez (Engineering Lead)  
**Note-taker:** Ethan Brooks

## Agenda

- Review customer feedback on shipment update latency
- Discuss API v2.0 feature set
- Define rollout and monitoring plan

## Discussion

- **Emily:** “We’ve got a bunch of tickets complaining that shipment status updates are lagging. The last incident exposed our rate‑limit logic—customers were hitting 429s unexpectedly.”  
- **Luis:** “The current algorithm is a simple token bucket. It’s fine for low traffic but not for bursty patterns we see from our beta partners.”  
- **Maya:** “If we can ship real‑time tracking endpoints, we’ll close the loop on the feedback loop. Also, a smarter rate limiter could reduce the error rate.”  
- **Ethan:** “I’ve drafted a monitoring plan: enable latency and error metrics on the new endpoints, and set a 2 % error‑rate threshold for a 48‑hour window. If we exceed that, we’ll roll back.”  
- **Emily:** “Sounds good. We’ll start with beta customers first. That gives us a safety net.”  
- **Luis:** “We’ll need to tweak the deployment pipeline to support a staged rollout.”  
- **Maya:** “Let’s also document the new endpoints in Confluence so the support team can help customers.”  

## Decisions

- Launch API v2.0 on 1 Nov 2023 with real‑time tracking endpoints and a new rate‑limiting algorithm.  
- Roll out to beta customers first, with monitoring enabled for latency and error metrics.  
- If error rate exceeds 2 % within 48 hours, roll back the deployment.

Maya Patel and Daniel Kim founded Helix Logistics in the spring of 2020, turning a cramped apartment into a makeshift office and hiring five engineers to turn a sketch into a minimal viable product. The core team—software engineer Alex Rivera, front‑end developer Priya Nair, data specialist Omar Hassan, DevOps lead Sara Chen, and QA engineer Miguel Torres—worked around the clock to build a lightweight shipment‑tracking dashboard and a simple REST API that could ingest carrier data and expose real‑time status updates. The first version of the product was a single‑page app that pulled data from a PostgreSQL database and displayed it on a map, while the API accepted JSON payloads and returned a status code and ETA. The team used Figma to iterate on the UI, Linear to track bugs and feature requests, HubSpot to log early customer interactions, and Otter.ai to capture meeting notes, but formal product documentation was largely absent; the README on GitHub was the only written guide.

The pilot with Midwest Freight Lines, a regional carrier with 120 trucks, began in late summer. The carrier’s operations manager, Lisa Grant, signed a one‑month trial after a brief demo, and the Helix team integrated the carrier’s existing EDI feed into the API. During the first week of the pilot, a misconfigured database connection caused a 15‑minute outage that left the carrier’s dispatch team unable to see real‑time truck locations. The incident was quickly resolved by rolling back to the previous database schema and patching the connection string, but it prompted the team to adopt a more rigorous testing regime and to document the deployment process in a shared Confluence space—an effort that was only partially completed before the year ended. The pilot also revealed that the UI was too cluttered for the carrier’s drivers, so the team decided to reverse their initial plan to ship a full‑featured dashboard and instead focus on a lightweight API that could be consumed by the carrier’s own mobile app.

By the end of 2020, Helix Logistics had a working MVP, a core engineering team, and a first pilot customer that had begun to trust the system enough to share its data. The company’s documentation remained sparse, with only a handful of internal notes and a README, but the adoption of HubSpot, Linear, Otter.ai, and Figma laid the groundwork for more disciplined processes. With the MVP in hand and the first pilot underway, Helix Logistics was poised to scale its API and tackle the growing demands of the freight industry in 2021.

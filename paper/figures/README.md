# Figures

Source PDFs for every figure go here. The paper references them with
`\includegraphics{figures/<name>.pdf}`. Export figures as **PDF (vector)** at
`dpi=300`, matching the body font size, using a colorblind-safe palette
(viridis / Okabe-Ito) and the `science` matplotlib style. See
`../../docs/publishing-a-paper-2026.md` sections 1.5 and 5.2.

Committed `*.pdf` assets in this directory are tracked by git (the paper
`.gitignore` ignores the root `main.pdf` build output but allows `figures/*.pdf`).

## teaser_placeholder.pdf

A trivial placeholder teaser was (or was not) generated by
`scripts/make_teaser_placeholder.py` depending on whether matplotlib was
available at scaffold time. If `teaser_placeholder.pdf` is absent, the paper
falls back to a framed TODO box (see the `\IfFileExists` guard in `main.tex`).
To (re)generate it:

```bash
python scripts/make_teaser_placeholder.py
```

Replace it with the real system diagram before submission.
